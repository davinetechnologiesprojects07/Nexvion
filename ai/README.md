# Nexvion AI-Assisted DevOps Analysis

AI assistance is used during incident and log investigation to provide:

- Error classification
- Severity assessment
- Possible root-cause identification
- Investigation guidance
- Suggested remediation

The AI recommendation does not automatically modify production infrastructure.
Suggested actions are validated using system logs and operational commands before
changes are applied.

- `incident-analysis.md`
- `incident-prompt-template.md`
